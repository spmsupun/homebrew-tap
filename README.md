# Homebrew tap

Homebrew casks for apps by [@spmsupun](https://github.com/spmsupun).

```sh
brew install --cask spmsupun/tap/brix
```

| Cask | App |
|---|---|
| `brix` | [Brix](https://github.com/spmsupun/brix): a native macOS workspace for developers who build with AI coding agents |

Update with `brew upgrade --cask brix`. Remove with `brew uninstall --cask brix` (add `--zap` to also remove its settings and data).
